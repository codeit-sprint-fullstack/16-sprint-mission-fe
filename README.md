# 판다마켓 스프린트 미션

HTML과 CSS를 사용하여 판다마켓 랜딩 페이지, 로그인 페이지, 회원가입 페이지를 구현했습니다.

## 구현 페이지

- 랜딩 페이지
- 로그인 페이지
- 회원가입 페이지

## 주요 기능

- 판다마켓 로고 클릭 시 루트 페이지 이동
- 로그인 페이지에서 회원가입 페이지 이동
- 회원가입 페이지에서 로그인 페이지 이동
- Google / Kakao SNS 링크 연결
- input focus 시 파란색 테두리 적용

## 사용 기술

- HTML
- CSS
- Git
- GitHub
