# 🐼 판다마켓

> _중고 물품을 거래할 수 있는 판다마켓 웹페이지를 HTML과 CSS를 활용하여 구현한 연습 프로젝트입니다.

## 📌 프로젝트 소개

판다마켓의 디자인과 레이아웃을 참고하여 웹페이지를 직접 구현했습니다.
HTML을 사용해 웹페이지의 구조를 구성하고, CSS를 활용해 실제 서비스와 유사한 화면을 구현하는 것을 목표로 했습니다.


## 🛠️ 사용 기술

   - HTML5
   - CSS3
   - Git / GitHub💪

## 📄 구현 페이지

   - 메인 페이지
   - 로그인 페이지
   - 회원가입 페이지
   
## 💻 주요 구현 내용

   - 웹페이지 기본 레이아웃 구성
   - Header / Footer 구현
   - 로그인 및 회원가입 Form 구성
   - Input 및 Button 스타일링
   - Flex를 활용한 요소 배치
   - 반응형 레이아웃 구현
