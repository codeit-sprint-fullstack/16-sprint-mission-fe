# 🚀 Sprint Mission 2 - 판다마켓 구현

코드잇(Codeit) 스프린트 미션 2 과정입니다. 판다마켓의 로그인 페이지와 회원가입 페이지를 구현하고 Netlify를 통해 배포하였습니다.

기본 요구사항에 맞추어 디벨롭했고, 심화요구사항 및 js를 통해 디벨롭해야 하는 부분은 버전업 하면서 리펙토링 할 예정입니다.

---

## 📌 주요 변경사항 및 기능 구현

### 🌐 공통 요구사항
- **로고 인터랙션**: "판다마켓" 로고 클릭 시 루트 페이지(`/`)로 이동
- **SNS 링크**: 각 SNS 아이콘 클릭 시 지정된 외부 링크(구글, 카카오)로 이동
- **Git & 배포**: 
  - 커밋 작성 및 코멘트 작성.
  - HTML/CSS 파일 Netlify 배포 완료

### 🔑 로그인 페이지 (`/login`)
- "회원가입" 버튼 클릭 시 회원가입 페이지(`/signup`)로 이동

### 📝 회원가입 페이지 (`/signup`)
- "로그인" 버튼 클릭 시 로그인 페이지(`/login`)로 이동
