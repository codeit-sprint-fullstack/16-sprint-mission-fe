# 판다마켓 로그인 / 회원가입 페이지

판다마켓의 로그인 및 회원가입 페이지를 구현한 파일입니다.

## 구현 페이지

- 로그인 페이지
- 회원가입 페이지

## 사용 기술

-HTML
-CSS

## 주요 기능

- 이메일 및 비밀번호 입력 폼
- 회원가입 시 닉네임 및 비밀번호 확인 입력 폼
- 입력창 포커스 시 테두리 색상 변경
- google, kakao 간편 로그인 링크
- 로그인 페이지와 회원가입 페이지 간 이동
- 반응형 레이아웃
